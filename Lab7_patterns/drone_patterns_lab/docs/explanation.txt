Лабораторна №7 — що тут відбувається
=====================================

Мета
- Показати кілька шаблонів проектування у єдиному сценарії «місій дронів»: Template Method, Bridge, Strategy, Observer, Abstract/Factory Method, Chain of Responsibility + простий HTTP API.

Головні ідеї
1) Template Method: базовий клас DroneMission задає незмінний порядок кроків (завантажити конфіг, підписатися на події середовища, аналіз, префлайт, навігація, корисне навантаження, реакції, збір даних, повернення, постпроцесинг). Конкретні місії перевизначають тільки корисне навантаження/особливості.
2) Bridge: логіка місії працює через DroneController (абстракція), який делегує рух платформи конкретній реалізації MovementImplementor (Air/Sea/Surface). Місія не знає деталей руху.
3) Observer: Environment генерує показники (вітер/хвилі/тріщини) і публікує події через EventBus; місія підписується і реагує.
4) Strategy: різні ReactionStrategy (WindReaction/WaveReaction/CrackReaction) описують, як місія поводиться на певний вплив середовища.
5) Chain of Responsibility: ланцюжок фейлсейфів (ReRoute → AdjustAltitude → SwarmReassign → EmergencyLand) послідовно намагається вирішити проблему.
6) Factory: MissionFactory за конфігом збирає місію: створює середовище, платформу, контролер, стратегію, ланцюжок безпеки та конкретний клас місії.
7) HTTP API: мінімальні ендпоїнти для запуску/статусу/результату місії (FastAPI).

Як читати лог демо
- `demo.py` створює sea_exploration місію з хвильовою стратегією.
- Takeoff/Navigate — старт і рух до цілі.
- Adjusting course — рух для «сонарного скану» (payload) та корекція на хвилю.
- Rerouting/Navigate base — фейлсейф вирішив повернутись на базу (задіяно ReRouteHandler).
- Landing — посадка.
- `Mission executed: {...}` — результат: id, зібрані дані, послідовність кроків Template Method (steps).

Що треба зробити студенту
- Зрозуміти зв’язки патернів (див. README, design.md, UML.png).
- Запустити тести (`pytest`) і API (`uvicorn drones.api.server:app --reload`) або демо (`python demo.py`).
- Можна додати свої місії/стратегії/платформи, зареєструвавши їх у фабриці.
